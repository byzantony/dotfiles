(use-package org
  :after denote
  :bind (("C-c c" . org-capture)
         ("C-c l" . org-store-link))
  :custom
  (org-startup-indented t)
  (org-hide-emphasis-markers t)
  (org-startup-with-inline-images t)
  (org-image-actual-width '(450))
  (org-pretty-entities t)
  (org-use-sub-superscripts "{}")
  (org-id-link-to-org-use-id t)
  (org-fold-catch-invisible-edits 'show)
  (org-default-notes-file ews-inbox-file)   ; EWS inbox for fleeting notes
  (org-capture-bookmark nil)

  :config
  (require 'denote)   ; Required for permanent notes

  ;; Explicitly define the full set of templates (fleeting + permanent + todo)
  (setq org-capture-templates
        '(("f" "Fleeting note" item (file+headline org-default-notes-file "Notes")
           "- %?")
          ("p" "Permanent note" plain (file denote-last-path)
           #'denote-org-capture
           :no-save t :immediate-finish nil :kill-buffer t :jump-to-captured t)
          ("t" "Todo" entry (file+headline ews-inbox-file "Tasks")
           "* TODO %?\n  %i\n  %a"))))

* Tangle on Save

Add this at the very end of `config.org`:

#+begin_src emacs-lisp :tangle no
;; Tangle this file on save (uncomment if you want automatic tangling)
(add-hook 'after-save-hook
           (lambda ()
             (when (string= (buffer-file-name) (expand-file-name "config.org" user-emacs-directory))
               (org-babel-tangle)))
           nil 'local)
#+end_src

### How to Use It

1. Save the `config.org` file.
2. Restart Emacs → it will automatically tangle all code blocks marked `:tangle yes` into `config.el` and load it.
3. You can now freely add headings, explanations, TODOs, and reorganise sections without breaking the config.

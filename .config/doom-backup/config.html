1. Introduction

This is my literate Doom Emacs configuration. All code blocks below are automatically tangled when you run doom sync.

After making changes, run doom sync in the terminal and restart Emacs.

7. Olivetti Mode

(after! olivetti
  (defun my/olivetti-setup ()
    "Hide line numbers and use variable-pitch font when Olivetti is enabled."
    (if olivetti-mode
        (progn
          (variable-pitch-mode 1)
          (setq-local display-line-numbers nil)
          (setq-local line-spacing 0.2))
      (variable-pitch-mode -1)
      (setq-local display-line-numbers display-line-numbers-type)))

  (add-hook 'olivetti-mode-hook #'my/olivetti-setup))

9. Citations (Zotero + Citar + Turabian)

This setup provides Turabian/Chicago Notes-Bibliography style footnotes:

  • First reference → full citation in footnote
  • Subsequent references → shortened form (Surname, Short Title, page)

Uses org-cite with Citar for searchable insertion. Org-roam citation interception is disabled so citations export correctly via biblatex.

9.1. Citar

(after! citar
  (setq citar-bibliography '("~/Documents/org/references.bib")
        citar-library-paths '("/mnt/data/library/pdfs"
                              "/mnt/data/library/journal articles")
        citar-open-entry-in-zotero t))

9.2. Org-Cite

(after! oc
  (setq org-cite-global-bibliography '("~/Documents/org/references.bib"))
  (setq org-cite-insert-processor   'citar
        org-cite-follow-processor   'citar
        org-cite-activate-processor 'citar)
  (setq org-cite-export-processors
        '((latex biblatex)
          (t     csl))))

9.3. Disable Org-Roam Citation Interception

(after! citar-org-roam
  (citar-org-roam-mode -1))

9.4. Per-File Header

Add these lines at the top of any Org file that needs citations: 

#+bibliography: ~/Documents/org/references.bib
#+cite_export: biblatex
#+latex_header: \usepackage[notes,backend=biber]{biblatex-chicago}

9.5. Usage

  • Insert citation: SPC m @ (works inside footnotes too)
  • Create footnote: C-c C-x f
  • Open attached PDF: select reference in Citar → choose PDF action
  • Export to PDF: C-c C-e l p

10. Document Export

10.1. PDF Compile Chain

(after! org
  (setq org-export-in-background t)
  (setq org-latex-pdf-process
        '("pdflatex -interaction nonstopmode -output-directory %o %f"
          "biber %b"
          "pdflatex -interaction nonstopmode -output-directory %o %f"
          "pdflatex -interaction nonstopmode -output-directory %o %f")))

10.2. Auto-Export PDF on Save

Exports to PDF on every save. Skips config.org to avoid tangling issues. 

(after! org
  (defun my/org-auto-export-pdf ()
    "Export current org file to PDF on save, skipping config.org."
    (when (and (eq major-mode 'org-mode)
               (buffer-file-name)
               (not (string-match-p "config\\.org$" (buffer-file-name))))
      (org-latex-export-to-pdf t)))

  (add-hook 'after-save-hook #'my/org-auto-export-pdf))

10.3. Open PDF in Zathura

Opens the compiled PDF alongside Emacs. Zathura auto-refreshes on each recompile. Bound to SPC m v. 

(defun my/org-open-pdf-preview ()
  "Open the PDF export of the current org file in Zathura."
  (interactive)
  (let ((pdf-file (concat (file-name-sans-extension (buffer-file-name)) ".pdf")))
    (unless (file-exists-p pdf-file)
      (org-latex-export-to-pdf))
    (start-process "zathura" nil "zathura" pdf-file)))

10.4. HTML Preview

Live HTML preview in a split Emacs window via xwidget. Refreshes on save. Useful for reading standard org notes — does not render biblatex citations. Bound to SPC m h. 

(defun my/org-preview-html ()
  "Export current org file to HTML and open in browser."
  (interactive)
  (let ((html-file (concat (file-name-sans-extension (buffer-file-name)) ".html")))
    (org-html-export-to-html)
    (browse-url (concat "file://" html-file))))

(after! org
  (map! :map org-mode-map
        :localleader
        :desc "Preview HTML in browser" "h" #'my/org-preview-html))

10.5. Book Layout (6×9 Print PDF)

Custom LaTeX class for book-style PDF export. Use #+latex_class: mybook in the per-file header alongside the citation headers. Produces Turabian-compatible footnotes, EB Garamond font, Chicago chapter/section styling, and print-ready margins. 

(after! ox-latex
  (add-to-list 'org-latex-classes
    '("mybook"
      "\\documentclass[11pt,twoside]{book}
[NO-DEFAULT-PACKAGES]
\\usepackage[utf8]{inputenc}
\\usepackage[T1]{fontenc}
\\usepackage{ebgaramond}
\\usepackage[paperwidth=6in,paperheight=9in,
             top=0.625in,bottom=0.625in,
             inner=0.875in,outer=0.625in]{geometry}
\\usepackage{microtype}
\\usepackage{graphicx}
\\usepackage{longtable}
\\usepackage{wrapfig}
\\usepackage{rotating}
\\usepackage{ulem}
\\usepackage{amsmath}
\\usepackage{amssymb}
\\usepackage{capt-of}
\\usepackage{hyperref}
\\usepackage{fancyhdr}
\\usepackage{titlesec}
% Chapter title: 'Chapter N' then title in small caps with top padding
\\titleformat{\\chapter}[display]
  {\\normalfont\\large\\centering}
  {Chapter \\thechapter}
  {1ex}
  {\\Large\\scshape}
\\titlespacing*{\\chapter}{0pt}{2.5in}{1.5em}
% Section: no number, centered
\\titleformat{\\section}[block]
  {\\normalfont\\large\\centering}
  {}
  {0pt}
  {}
\\titlespacing*{\\section}{0pt}{1.5em}{0.75em}
% Subsection: no number, centered, italic
\\titleformat{\\subsection}[block]
  {\\normalfont\\normalsize\\centering\\itshape}
  {}
  {0pt}
  {}
\\titlespacing*{\\subsection}{0pt}{1em}{0.5em}
% Running header: chapter title centered, no rule
\\pagestyle{fancy}
\\fancyhf{}
\\renewcommand{\\chaptermark}[1]{\\markboth{#1}{}}
\\fancyhead[C]{\\small\\itshape\\leftmark}
\\fancyfoot[C]{\\thepage}
\\renewcommand{\\headrulewidth}{0pt}
\\fancypagestyle{plain}{%
  \\fancyhf{}%
  \\fancyfoot[C]{\\thepage}%
  \\renewcommand{\\headrulewidth}{0pt}%
}
% Footnote padding
\\setlength{\\skip\\footins}{1.5em}
\\addtolength{\\footnotesep}{4pt}
% No section numbers
\\setcounter{secnumdepth}{0}
[EXTRA]"
      ("\\chapter{%s}"       . "\\chapter*{%s}")
      ("\\section{%s}"       . "\\section*{%s}")
      ("\\subsection{%s}"    . "\\subsection*{%s}")
      ("\\subsubsection{%s}" . "\\subsubsection*{%s}"))))
